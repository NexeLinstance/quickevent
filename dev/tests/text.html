Text Commands

1. setText

Replaces the text content of the target.

Target:
initial

2. appendText

Appends text to the end of the target.

Target:
start

3. prependText

Prepends text to the beginning of the target.

Target:
end

4. getText (Basic)

Gets text from a source and puts it somewhere else.

Source:
source text
Result:
(empty)

5. getText (Alias & Template)

Gets text into a variable, then uses it in a template.

Source:
Ali
Result:
(empty)

6. getText (Expression & Math)

Processes the text using string/math functions.

Source:
hello world
Result:
(empty)

7. getText (Multiple Elements)

When a selector matches multiple elements, it returns an array.

Sources:
A
B
C
Result:
(empty)

8. Errors (Expected in Console)

These actions will fail and report to the right panel.

Target:
still works
