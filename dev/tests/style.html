Style commands

addStyle

Add individual inline styles. Existing styles are preserved.

Target: text

removeStyle

Remove one inline property.

Target: text

toggleStyle

Pass prop:value to toggle between empty and that value.

Target: text

setStyle

Replace all inline styles with the given set.

Target: text
