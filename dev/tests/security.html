QuickEvent · Security Test Suite

Click each button to simulate an attack. Check the console and the result box.

1. Prototype Pollution (callFunc)

Attempts to pollute the global Object prototype using __proto__ or constructor.

Check if window has been polluted.

2. XSS via setHtml (Sanitization)

Attempts to inject a script tag or an onerror handler.

(Clean HTML will be injected here)

3. Unsafe Redirect (javascript:)

Attempts to execute JS via a malicious URL scheme.

4. Cookie Injection

Attempts to break out of the cookie path using semicolons.

Check Application > Cookies. Only 'test' on localhost should exist.

5. AJAX Head Injection

Attempts to load a script from an untrusted origin.

6. runFunc Malicious Import

Attempts to load a JS module from a `data:` URI.

7. Stack Overflow (Recursive Call)

Attempts to cause a Maximum Call Stack Size Exceeded error.
